# হাজী চান মিয়া স্কুল — ম্যানেজমেন্ট সিস্টেম

Next.js 15 (App Router) · JavaScript · Tailwind · MongoDB (Mongoose) · Cloudflare R2 · JWT

## সেটআপ
1. `npm install`
2. `.env.example` → `.env.local` (সব মান বসান; **MongoDB Atlas** লাগবে — ট্রানজ্যাকশনের জন্য replica set দরকার)
3. পুরনো ডেটা থাকলে: `npm run migrate` (নিরাপদ, বারবার চালানো যায়; পুরনো `fees`/`accounts` কালেকশন মোছে না)
4. নতুন ইনস্টলে প্রথম সুপার অ্যাডমিন: `ADMIN_PASSWORD=... npm run seed`
5. `npm run dev` → `/login`; স্কুলের তথ্য, শ্রেণি/শাখা, প্রারম্ভিক জের, অনুমতি: **অ্যাডমিন → সেটিংস**

## Vercel ডেপ্লয়
Environment Variables এ `.env.example` এর সব মান দিন। প্রথম ডেপ্লয়ের আগে নিজের কম্পিউটার থেকে `npm run migrate` (পুরনো ডেটা থাকলে) ও `npm run seed` চালান। R2 bucket এ Public access চালু করুন।

## ফেজ ৩ যা যোগ হয়েছে
- **একাডেমিক:** সেশন, বিষয় (বাধ্যতামূলক/ঐচ্ছিক), ক্লাস টিচার ও বিষয় শিক্ষক নিয়োগ — মেনু: "শ্রেণি-বিষয়-নিয়োগ"। শ্রেণি/শাখা সেটিংস থেকে।
- **শিক্ষক অ্যাক্সেস:** শিক্ষক শুধু নিয়োগকৃত শ্রেণি দেখেন; হাজিরা শুধু ক্লাস টিচার; নম্বর ক্লাস টিচার বা সেই বিষয়ের শিক্ষক। **নিয়োগ না দিলে শিক্ষক কিছুই দেখবেন না** (সেটিংসে সীমা বন্ধ করা যায়)।
- **শিক্ষার্থী:** স্বয়ংক্রিয় আইডি/পাসওয়ার্ড/রোল, প্রোফাইল, ইতিহাস, কাগজপত্র (R2), ঐচ্ছিক বিষয়, প্রমোশন, পাস, বদলি, ঝরে পড়া, রোল পুনর্বিন্যাস, CSV এক্সপোর্ট/আমদানি।
- **ভর্তির আবেদন:** পাবলিক ফর্ম `/admission` → অ্যাডমিন প্যানেলে অনুমোদন/প্রত্যাখ্যান।
- **ছুটি:** স্টাফ ও শিক্ষার্থীর আবেদন, অনুমোদনে হাজিরায় "ছুটি" বসে। **স্টাফ হাজিরা** ও **হাজিরা রিপোর্ট** (মাসিক/বার্ষিক/অনুপস্থিতের তালিকা, প্রিন্ট, CSV)।
- আপগ্রেডের পর `npm run migrate` চালান (status/ইতিহাস বসাবে; নতুন অনুমতিগুলো আগের কাস্টম অনুমতিতে ডিফল্ট অনুযায়ী যোগ হয়, লক-আউট হয় না)।
- ডকুমেন্ট আপলোডে `R2_PUBLIC_URL` আবশ্যক।

## হিসাবের নিয়ম
- ইনভয়েস = ফি-এর দায়। পেমেন্ট প্রতিটি আলাদা লেনদেন (অনন্য রসিদ নং), কখনও ওভাররাইট হয় না।
- বকেয়া = (ধার্য + জরিমানা − ডিসকাউন্ট) − (পেমেন্ট − রিফান্ড), বাতিল লেনদেন বাদে।
- পেমেন্ট/রিফান্ড করলে একই ট্রানজ্যাকশনে ক্যাশবুকে আয়/ব্যয় এন্ট্রি তৈরি হয় — হাতে আবার তোলা যায় না।
- ভুল হলে মোছা নয়, কারণসহ বাতিল; সব কাজ অডিট লগে।
- ক্যাশবুক + লেজার পদ্ধতি (ডাবল-এন্ট্রি নয়): নগদ/বিকাশ/নগদ(Nagad)/ব্যাংক অ্যাকাউন্টের প্রারম্ভিক ও সমাপনী জের।
